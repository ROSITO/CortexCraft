# Support

## How to get help

| Need | Where |
| ---- | ----- |
| Bug | [GitHub Issues](https://github.com/ROSITO/CortexCraft/issues/new?template=bug_report.yml) |
| Feature idea | [GitHub Issues](https://github.com/ROSITO/CortexCraft/issues/new?template=feature_request.yml) |
| Usage / setup question | [GitHub Discussions](https://github.com/ROSITO/CortexCraft/discussions) (when enabled) or an issue labeled `question` |
| Security vulnerability | [SECURITY.md](SECURITY.md) — **not** a public issue |
| Code of Conduct report | Private advisory / maintainer contact (see [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md)) |

## What to include

- CortexCraft version (`0.1.0` or git commit)
- macOS version
- Steps to reproduce
- Whether a vault path / Claude headless / MCP is involved (no secrets)

## Maintainer contact

- GitHub: [@ROSITO](https://github.com/ROSITO)
- Prefer repository Issues / Security advisories so the community can benefit from the resolution.

We do not offer private paid support for this open-source project.
